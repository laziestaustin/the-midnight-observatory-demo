# 午夜天文台 · 公开试玩

版本 0.19.1。选择 A/1986 或 B/2066 后直接在浏览器开始，无需下载 ZIP。两位玩家分别选一个角色并保持语音通话，进度保存在当前浏览器。第二至第五幕仍是明确标识的交互与美术占位样机。首页「章节测试 / 跳关」或游戏内「章节」可分别进入第一至第五幕；测试存档与正常剧情分开保存。

## 网页发布

本仓库只保存试玩网页及运行素材。在线入口：https://laziestaustin.github.io/the-midnight-observatory-demo/ 。gh-pages分支更新后由GitHub Pages发布，版本是否已上线以对应提交的Actions部署结果为准。原项目保持私有。

游戏程序与同版本 0.19.1 离线版一致，本机浏览器额外验证了网页入口、子路径素材加载、拾取、拖动、刷新保存及手机入口。公开网址的发布状态需另外确认。两端完全独立，可以在两台电脑分别游玩，通过实际通话传递线索。第三幕由A提供底片封存校验，B手动打开安装隔层，不读取另一端的状态。第四幕三项观测独立确认；B提供星图和观测档案，A按同名任务操作；单项失败或重做不影响另外两项。第五幕包含档案推理：A有八张完整影像和现场装片便条，B有三条值夜记录及编号封套；合并证据判断第一次／第二次拍摄，分别拖放并确认照片，直接打开对应拍摄记录（对照示意可选）、复现终段异常；A成功拍摄后读取新照片上的星迹起点、终点格位；B记录这两处格位，核对后才能盖章与开门。旧存档保留选片和档案，仅重置B最后的盖章与开门状态。网站没有账户后台或远端同步，新网站与本地文件的存档因浏览器来源不同而分离。

## 天文参考数据与署名

第四幕参考星取自 [HYG Database v4.1](https://github.com/astronexus/HYG-Database/blob/main/hyg/CURRENT/hygdata_v41.csv)，署名 David Nash / Astronexus，原数据及本次三行坐标改编采用 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。此许可适用于目录及其衍生坐标数据，不自动适用于游戏代码或美术。输入为J2000/ICRS位置、自行和视向速度，经Astropy 7.2.0换算到测站52°N、0°E、50m，1986-11-17T23:48:00Z的无折射地平方位/高度，取整度：织女星（HIP91262）326°/9°；天津四（HIP102098）310°/27°；五车二（HIP24608）100°/73°。北0°向东顺时针，高度从几何地平线向上。背景星点为示意；人工检定靶、历史异常、流星与时空事件为游戏设定。
