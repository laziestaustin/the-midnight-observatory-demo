# 午夜天文台 · 公开试玩

版本 0.9.0。选择 A/1986 或 B/2066 后直接在浏览器开始，无需下载 ZIP。两位玩家分别选一个角色并保持语音通话，进度保存在当前浏览器。第二、三幕仍是明确标识的交互与美术占位样机。首页「章节测试 / 跳关」或游戏内「章节」可分别进入第一至第三幕；测试存档与正常剧情分开保存。

## 网页发布

本仓库只保存试玩网页及运行素材。在线入口：https://laziestaustin.github.io/the-midnight-observatory-demo/ 。gh-pages分支更新后由GitHub Pages发布，版本是否已上线以对应提交的Actions部署结果为准。原项目保持私有。

游戏程序与同版本 0.9.0 离线版一致，本机浏览器额外验证了网页入口、子路径素材加载、拾取、拖动、刷新保存及手机入口。公开网址的发布状态需另外确认。网站没有账户后台或自动远端同步，新网站与本地文件的存档因浏览器来源不同而分离。
