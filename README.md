# 午夜天文台 · 公开试玩

版本 0.24.0。选择 A/1986 或 B/2066 后直接在浏览器开始，无需下载 ZIP。两名主角是一对约在2026年11月17日看狮子座流星雨的情侣，却落入1986年与2066年。电话相认、出口受阻、旧案和应急指南逐幕揭示共同观测的脱困条件。两位玩家分别选一个角色并保持语音通话，进度保存在当前浏览器。五个独立场地已接第一版场景美术；大厅与穹顶各有四向环视，机关特写和演出仍待精修。首页「章节测试 / 跳关」或游戏内「章节」可分别进入第一至第五幕；测试存档与正常剧情分开保存。

## 网页发布

本仓库只保存试玩网页及运行素材。在线入口：https://laziestaustin.github.io/the-midnight-observatory-demo/ 。gh-pages分支更新后由GitHub Pages发布，版本是否已上线以对应提交的Actions部署结果为准。原项目保持私有。

游戏程序与同版本 0.24.0 离线版一致，本机浏览器额外验证了网页入口、子路径素材加载、拾取、拖动、刷新保存及手机入口。公开网址的发布状态需另外确认。两端完全独立，可以在两台电脑分别游玩，通过实际通话传递线索。第三幕由A提供底片封存校验，B手动打开安装隔层，不读取另一端的状态。第四幕三项观测独立确认；B提供星图和观测档案，A按同名任务操作；单项失败或重做不影响另外两项。第五幕包含档案推理：A有八张完整影像和现场装片便条，B有三条值夜记录及编号封套；合并证据判断第一次／第二次拍摄，分别拖放并确认照片，直接打开对应拍摄记录（对照示意可选）、复现终段异常；A成功拍摄后读取新照片上的星迹起点、终点格位；B记录这两处格位，核对后盖章。随后两人到窗前实际通话倒数，各自看完11秒异常星迹，再沿侧翼折返楼梯回到大厅原来的出口。v0.19.1有效结局保留；更早没有照片核对的B旧盖章需要重新核对，选片和档案保留。网站没有账户后台或远端同步，新网站与本地文件的存档因浏览器来源不同而分离。

## 本版本美术样板

第一幕大厅八个年代/视角按同一结构与色彩标准制作；柜子分层样板沿用v0.23。其余机关终稿、高清母稿、最终拟音和真人盲测尚未完成。 大厅前、右、后、左均来自同一观察点，两个时代保持对应门框与物件。阅览台使用须知、工作桌旧值夜簿、观测告示及站内通路图各有明确位置和不同用途。主场景与检查画面共用柜门投影和取物状态，前景按实际层级遮挡。新不透明稿原生1671–1672×941，门面图集887×1774，运行文件无损保留源像素。本轮内置出图7次包含修正前草稿，额外外部付费图片API调用0次；未将样板宣称为2560×1440或4K母稿，也未将第一幕标记为封版。
